# Sarath Portfolio

Minimal scroll-story portfolio for Sarath Krishnan P V, built with React, TypeScript, Vite, and a subtle Three.js layer.

## Local

```powershell
npm install
npm run dev
```

## Build

```powershell
npm run build
```

## GitHub Pages

This project is configured for a GitHub Pages project site at:

```txt
https://PVSarathKrishnan.github.io/Portfolio/
```
